# ДОРАБОТКА ПРОЕКТА «Сомной_легко»

Это авторский сайт специалиста, который помогает людям использовать искусственный интеллект в работе и жизни.

Дизайн должен вызывать доверие, ощущение спокойной компетентности и желание начать диалог.

Не создавать новый сайт.

Не переписывать существующий проект.

Не менять структуру файлов.

Работать только с существующим проектом на HTML, CSS и JavaScript.

Все изменения должны быть аккуратно встроены в текущую архитектуру.

Использовать существующие фотографии проекта.

Не заменять фотографии.

Не генерировать новые изображения.

Не использовать фотографии из интернета.

Не менять фотографии местами.

# 1. Hero

Полностью переработать первый экран.

Это самая важная часть сайта.

Главный экран должен производить впечатление спокойствия, уверенности и профессионализма.

Он должен создавать ощущение, что перед пользователем специалист, который умеет делать сложные вещи простыми.

Главный акцент — крупный заголовок.

---

## Анимация заголовка

Использовать современную элегантную анимацию первой строки.

Можно вдохновляться компонентами ReactBits, но реализовать эффект средствами HTML, CSS и JavaScript без использования React.

После появления главного заголовка на экране остается одна сильная фраза.

Например:

**«Сложные технологии — простым человеческим языком.»**

После этого один раз, сразу после загрузки страницы, появляется уточнение.

Например:

• Лендинги.

• Портфолио.

• Промостраницы.

• AI-first сайты.

• Digital-концепты.

• Интерфейсы.

• Спецпроекты.

Каждая следующая строка мягко проявляется с небольшой задержкой (около 0,2 секунды), словно мысль постепенно становится яснее.

После появления последней строки анимация полностью завершается.

Интерфейс остается статичным.

---

## Требования к анимации

Не использовать эффект печатной машинки.

Не использовать бесконечно повторяющиеся анимации текста.

Если используется анимация, она должна проигрываться только один раз после открытия страницы и больше не повторяться.

После завершения анимации интерфейс остается статичным.

Анимация должна быть едва заметной, элегантной и не отвлекать от чтения.

Она должна создавать ощущение дорогого, продуманного интерфейса, а не демонстрации анимационных эффектов.
